HardwareMonitor Dashboard

A real-time, fully customizable PC hardware monitoring dashboard for your browser. HWiNFO requires the remotehwinfo server to work, alongside support for LibreHardwareMonitor/OpenHardwareMonitor with their own built-in web server. No installation, no backend — a single HTML file that runs straight in your browser.

Features

Everything you need to build your own sensor dashboard — no coding required.

⚡ HWiNFO + remotehwinfo & LHM/OHM

Fetches data from HWiNFO via the remotehwinfo server, as well as directly from LibreHardwareMonitor's or OpenHardwareMonitor's own web server.

🎨 Themes & Resolutions

Built-in theme presets (like Cyberpunk Neon and Midnight Obsidian), free color choices, and scaling for your own dedicated sensor display.

🗂️ Flexible Card Management

Adjust card sizes, columns, and order. Drag cards into a new position right on the main dashboard, or collapse long configurations into tidy groups.

👁️ Live Preview

See your changes instantly in the settings panel with mock, animated data — no need to leave the settings screen to check the result.

🚨 Dynamic Color & Alerts

Set value thresholds that automatically change a chart's or sensor's color (e.g. green → orange → red), plus alert thresholds that trigger a warning border on the card.

📈 Trends & Sparklines

Show a small trend line next to individual metrics so you can see the direction at a glance without a full chart.

⏱️ Per-Card Refresh Rate

Override the global polling rate for an individual card — let your most critical metrics update faster than the rest of the dashboard.

💾 Export, Import & No Install

Back up or transfer your entire configuration as a JSON file. Everything is stored locally in your browser — no accounts, no cloud services, no backend server.

Quick Start Guide

  1. Download and extract the Dashboard.
  2. Run HWiNFO and the remotehwinfo server in the background, or alternatively LibreHardwareMonitor/OpenHardwareMonitor with its own web server.
  3. Open Dashboard.html in your browser or on a dedicated panel display.
  4. Set your IP addresses, ports, themes, and metrics in the settings panel (⚙️)!
